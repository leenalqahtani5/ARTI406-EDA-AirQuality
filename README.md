# ARTI406-EDA-AirQuality
Exploratory Data Analysis and Data Cleaning for Air Quality Dataset (ARTI 406 Assignment 1)
Dataset Name: Air Quality Dataset  

---

### Dataset Source
The dataset was obtained from the UCI Machine Learning Repository.  
It contains air quality measurements collected from sensors.

---

### Number of Rows and Columns
The dataset contains:
- Rows: 9471  
- Columns: 17 (before cleaning)

After data cleaning:
- Rows: 9357  
- Columns: 16  

---

### Description of Features (Columns)
- Date: Date of measurement  
- Time: Time of measurement  
- CO(GT): Carbon monoxide concentration  
- PT08.S1(CO): Sensor response for CO  
- NMHC(GT): Non-methane hydrocarbons concentration  
- C6H6(GT): Benzene concentration  
- PT08.S2(NMHC): Sensor response for NMHC  
- NOx(GT): Nitrogen oxides concentration  
- PT08.S3(NOx): Sensor response for NOx  
- NO2(GT): Nitrogen dioxide concentration  
- PT08.S4(NO2): Sensor response for NO2  
- PT08.S5(O3): Sensor response for ozone  
- T: Temperature  
- RH: Relative humidity  
- AH: Absolute humidity  

---

### Purpose of Using this Dataset

This dataset was used to apply data cleaning and exploratory data analysis (EDA) techniques. 
The goal is to understand air quality patterns, analyze relationships between variables, and prepare the data for further analysis or machine learning applications.

Additionally, this topic is interesting and engaging, as it relates to real-world environmental issues and helps in understanding how data can be used to monitor and improve air quality.
